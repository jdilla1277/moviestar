# Share finished videos with your agent — Moviestar v0.8.0

Moviestar v0.8.0 brings collaboration into the editing workflow. Ask your agent
to finish a video, upload it privately, and email someone a link they can watch
and download. The recipient can give that finished MP4 to their own agent for
the next edit.

Local editing still works without an account. Hosting is optional.

## Upload, share, and hand off

Connect an account once:

```sh
moviestar account connect you@example.com
# Complete email verification and human account/installation approval.
moviestar account status
```

Account setup includes explicit terms and age confirmation. Terminal email-code
setup is also supported where enabled by the hosting service; see the
[account guide](../accounts.md).

Upload first to keep a finished MP4 private, then share its returned video ID:

```sh
moviestar upload final.mp4
moviestar share VIDEO_ID --to editor@example.com
```

Or combine the upload and handoff:

```sh
moviestar share final.mp4 --to editor@example.com
```

The link is **unlisted and forwardable**. Anyone holding it can watch and
download without an account. Emailing it to one address does not restrict
access to that address. Provider acceptance is reported separately from link
creation and does not guarantee inbox delivery.

The initial Free allowance is three stored videos, 1 GB total, and 500 MB per
video, using decimal units. Uploads must pass validation as supported H.264 MP4
media, with AAC when audio is present, before sharing. No server transcoding is performed. New uploads that
would exceed a limit are rejected.

## Bring the video into another edit

Recipients can download the shared MP4 directly from their agent:

```sh
moviestar download WATCH_URL --out incoming/cut.mp4
moviestar probe incoming/cut.mp4
```

A download contains the finished video, not the original source files or
editable project history.

## Manage links and storage

```sh
moviestar shares
moviestar unshare LINK_ID
moviestar delete VIDEO_ID --dry-run
moviestar delete VIDEO_ID
```

Unsharing revokes one link and keeps the video and its storage usage. Deleting
an uploaded video disables all its links and frees quota after stored cleanup
completes. Already downloaded copies cannot be recalled; transfers already
started may finish. Local files and projects remain intact.

Interrupted commands return structured retry guidance. Keep upload/share/email
idempotency keys, and retry deletion with the same video ID. A pending or
unknown outcome must not be treated as confirmed deletion or unused quota.
See the [sharing guide](../sharing.md) for partial-success handling, link and
email history, pagination, and Preview origins.

## Editing and inspection improvements since v0.7.1

- Import caption files and transcribe a selected time range. `load --captions`
  can also retrieve available captions from a video page URL using the
  optional `url-captions` extra.
- Keep caption placement when regenerating, match caption rules across
  punctuation, and control size/placement relative to the output canvas.
- Preview screenshots against social-platform safe areas.
- Check stereo phase and speech before transcription; short all-speech clips
  remain eligible for transcription.
- Select explicit H.264 encoders, fall back to VideoToolbox on macOS when
  x264 is unavailable, and render oversized caption graphs through private
  filter scripts.
- Preserve fixes for odd-sized inputs and yuv420p output compatibility.

The skills-only Moviestar plugin is versioned with the package and includes
updated account, sharing, download, and deletion guidance.

## Upgrade

```sh
python -m pip install --upgrade "moviestar==0.8.0"
moviestar --version
moviestar doctor
```

Python 3.10 or newer, FFmpeg, and ffprobe are required. Existing local projects
need no migration for hosted sharing. The PyAV compatibility cap from v0.7.1
is retained. Moviestar remains licensed under Apache License 2.0.
