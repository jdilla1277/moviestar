# See more. Keep the edit moving. — Moviestar v0.8.4

Moviestar 0.8.4 improves local editing reliability and expands the remote CLI
for the Cloud developer preview. Upload private originals, inspect footage,
retrieve results, and manage project viewer access through your approved account.
The package and skills-only plugin use the same 0.8.4 version.

## Upgrade

```sh
# Account and Cloud commands, supplied captions, or --no-transcribe:
python -m pip install --upgrade 'moviestar==0.8.4'
# Local speech recognition:
python -m pip install --upgrade 'moviestar[transcribe]==0.8.4'
moviestar --version
```

Python 3.10+ is required. Local media editing needs FFmpeg and ffprobe. Cloud
commands need the base package and an approved installation, without a local
editing workspace, FFmpeg, or a speech model. Existing local projects do not need
a migration. Cloud service availability, consent, permissions and account limits
are checked independently of the installed client version.

## More reliable local edits and previews

- Recover missing recorder WebM durations instead of loading the source as zero
  seconds. Duration recovery keeps video timestamps usable for inspection/editing.
- Recover the last displayed frame after a valid screenshot seek produces no
  frame, including the final displayed-frame interval. Audio-only endings keep
  the final picture while preserving the longer authored audio duration.
- Preserve portrait storyboard frames when grid tiles require odd-height padding.
- Reject unresolved text styling on full-spec imports instead of silently
  rendering default typography. Complete historical style values remain supported.
- Validate persisted word-highlight tokens consistently before both dry-run
  success and application. Recognize explicit `text-shadow: none` resets.
- Reject holds within 1 ms of a scene end unless they are exactly at the end,
  with the precise scene-local value to use. Oversized audio join fades produce
  structured errors before FFmpeg planning. Previously saved bad holds can be
  corrected while preserving camera-rebasing behavior.
- Keep the final visual-activity sample at fractional file endings.

## Cloud developer preview

Connect only to the account and service you intend to use:

```sh
moviestar account status
# If disconnected, request and approve the connection in your browser:
moviestar account connect you@example.com
moviestar account status
moviestar cloud capabilities
```

Do not start another claim while approval is pending. A client update does not
enable a disabled server operation. Available Cloud jobs can consume your
account's processing allowance; retain their IDs and recovery keys.

### Private originals and viewer access

- Upload with `cloud assets create FILE`; retain its retry key, and recover an
  uncertain completion with `--resume UPLOAD_ID` rather than duplicating an original.
- List owned assets or discover accepted project-shared assets with `cloud assets
  list --shared`. Rename an owned asset's display name without changing its ID,
  original filename or bytes; stale rename comparisons fail safely.
- Download project originals and a manifest into a new folder with `cloud projects
  download PROJECT_ID --out ./originals`. This transfers originals, not an edit.
- Manage viewer invitations with `cloud projects share`, `access`,
  `resend-invitation` and `unshare`. New whole-project invitations can include
  current/future ready project assets; older metadata-only invitations keep
  their narrower permissions. Viewer access does not grant editing or resharing.
- Invite a viewer to one ready asset without a project using `cloud assets share`
  and manage its invitations with `access`, `resend-invitation` and `unshare`.
  Accepted viewers can use `cloud assets get ASSET_ID` to retrieve metadata and
  a private original-download URL. Recipient review and acceptance stay in the
  browser; revoking one invitation does not remove independent project access.
- Delete an owned project with `cloud projects delete PROJECT_ID --confirm`.
  Account originals and references in other projects are preserved; cleanup can
  remain pending after project access ends.

See [account assets](../account-assets.md) and [Cloud projects](../cloud-projects.md)
for supported formats, permission boundaries, pagination and recovery rules.

### Inspect existing Cloud footage

The remote CLI now supports:

| Command | Result |
| --- | --- |
| `cloud probe` | Metadata, plus optional bounded audio loudness measurements |
| `cloud screenshot` | One private frame at an asset timestamp |
| `cloud storyboard` | A labeled contact sheet |
| `cloud skim` | A small timestamped thumbnail sample |
| `cloud watch` | A bounded video/audio excerpt |
| `cloud activity` | Measured visual-change samples and candidate ranges |
| `cloud inspect` | Dense JPEG inspection of a short section |

Each operation has its own job/retrieval contract. Reopen the same saved job
without scheduling computation again. Polling timeouts do not cancel remote
work. Output downloads preserve existing files rather than overwriting them.
These tools use the selected asset's own clock; they do not apply unsaved edits
or infer a transcript. See the [Cloud docs index](../README.md) and each operation's
guide for exact CLI/API/MCP calls, bounds and retrieval behavior.

The [developer quickstart](https://trymoviestar.com/account/developer-docs/quickstart),
[asset lifecycle](https://trymoviestar.com/account/developer-docs/asset-lifecycle)
and [inspection guide](https://trymoviestar.com/account/developer-docs/inspect)
require a completed account. They describe enabled preview capabilities, not a
promise that every deployment supports them. Remote timeline editing, saved
edit revisions and edited-project rendering remain planned. The Cloud audio
surface under `experiments/` is a design mock outside the distributed package.
Hosted MCP deploys separately; the plugin remains skills-only.

## Agent guidance and feedback

- The skill explains model choice, transcript corrections, passage repair and
  timed-caption import. Source transcript changes and authored caption overlays
  are distinct; follow the [transcription and repair guide](../../plugins/moviestar/skills/moviestar/references/transcription.md).
- `cloud docs show PAGE` now returns Markdown by default. **Integrations that
  parse JSON must add `--json`.** Explicit `--markdown` works with 0.8.3 and 0.8.4;
  `cloud docs list` and errors remain JSON.
- User-approved connected feedback can retain server-verified reporter contact.
  `feedback --anonymous` skips account-state and credential access. Explicit
  alternate contact stays separate, and contacts are omitted from normal
  receipts and Discord fields. No device contact discovery, newsletter signup,
  or automatic follow-up is performed. Ambiguous authenticated deliveries report
  `anonymous: null` and warn against automatic resubmission.

Test-only changes also isolate account write failures from saved profiles and
keep dry-run assertions independent of optional transcription installation.
