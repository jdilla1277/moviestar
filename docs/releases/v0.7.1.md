# Transcription fix — Moviestar v0.7.1

Moviestar v0.7.1 restores transcription for new installations. It contains no
other behavior changes from [v0.7.0](v0.7.0.md).

## What's fixed

PyAV 19, released on 2026-09-29, removed an argument that faster-whisper 1.2.1
passes when it opens audio. Fresh installations of v0.7.0 resolved PyAV 19, and
every transcription — `moviestar load` without `--no-transcribe`,
`moviestar retranscribe`, and caption generation from new sources — failed
with:

```text
Transcription failed: open() got an unexpected keyword argument 'metadata_errors'
```

v0.7.1 requires `av<19`, so installations resolve a compatible PyAV release.
The cap will be lifted once a faster-whisper release supports PyAV 19; upstream
tracks this in
[SYSTRAN/faster-whisper#1492](https://github.com/SYSTRAN/faster-whisper/issues/1492).

## Upgrade

```bash
pip install --upgrade "moviestar==0.7.1"
moviestar doctor
```

If an existing environment already has PyAV 19, upgrading Moviestar downgrades
PyAV to a compatible release. Environments that installed v0.7.0 before
2026-09-29 were not affected.

Projects, specs, and transcripts from v0.7.0 need no changes. Moviestar v0.7.1
is licensed under the Apache License 2.0.
