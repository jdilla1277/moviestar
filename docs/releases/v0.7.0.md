# A video editor for AI agents — MovieStar v0.7.0

MovieStar gives AI agents a deterministic, non-destructive way to turn raw
footage into finished video. Agents can inspect media, make precise edits,
compose scenes, mix audio, add captions and overlays, and verify the result
through one structured command-line interface.

Explore MovieStar at **[trymoviestar.com](https://trymoviestar.com)**.

## What's new in v0.7.0

### MovieStar is now open source

The complete Python package, test suite, agent-facing documentation, and
portable MovieStar skill now live together in the public
[`jdilla1277/moviestar`](https://github.com/jdilla1277/moviestar) repository
under the Apache License 2.0. Agents and developers can inspect the entire
editing pipeline, propose changes, and build directly on the same tools shipped
through PyPI.

### Build transitions into the timeline

Authored scene transitions persist in project state and render through the same
deterministic timeline used by screenshots, previews, and exports. An agent can
plan a transition, inspect the resolved edit, and verify the finished output
without switching mental models.

### Correct captions without losing intent

Caption rules can replace phrases, split tokens safely, and report which
current captions they affect before an agent commits to a reload. That makes
repeatable cleanup possible without hand-editing generated subtitle files.

### Connect an optional account safely

A human can approve a named MovieStar installation through the website while
the CLI stores only its revocable device credential. The agent never receives
the sign-in link, and local editing remains fully available without an account.

### Keep the v0.6 editing foundation

The geometry, camera motion, silent-footage activity analysis, environment
diagnostics, and result-time audio verification introduced in v0.6.0 remain
available in this release.

## Try MovieStar

```bash
pip install --upgrade "moviestar==0.7.0"
moviestar doctor
```

Then visit the [getting-started guide](../getting-started.md) for a first
verified edit, or install the
[MovieStar skill](../install-skill.md) to give a compatible coding agent the
recommended workflow directly.
