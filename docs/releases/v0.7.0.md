# MovieStar v0.7.0 — Open-source, agent-native video editing

MovieStar v0.7.0 is the first release developed and distributed as open-source
software under the Apache License 2.0. The application, package documentation,
and portable MovieStar skill now live together in the public
[`jdilla1277/moviestar`](https://github.com/jdilla1277/moviestar) repository.

## Highlights

**Build with MovieStar in public.** The complete Python package, its tests,
agent-facing documentation, and the distributed skill are available for
inspection and contribution. Package metadata now routes users to the public
documentation, issue tracker, and source repository.

**Move cleanly between scenes.** Authored scene transitions persist in project
state and render through the same deterministic timeline used by screenshots,
previews, and exports.

**Correct captions without losing intent.** Caption rules can replace phrases,
split tokens safely, and report which current captions they affect before an
agent commits to a reload.

**Connect an optional account without exposing a sign-in link to an agent.** A
human can approve a named MovieStar installation through the website while the
CLI stores only its revocable device credential. Local editing remains fully
available without an account.

The geometry, camera motion, silent-footage activity analysis, environment
diagnostics, and result-time audio verification introduced in v0.6.0 remain
available in this release.

## License and upgrade notes

MovieStar v0.7.0 is licensed under the Apache License 2.0. Versions through
v0.6.0 remain under the Business Source License 1.1; the new license does not
retroactively relicense those historical packages.

The public repository begins with the v0.7.0 codebase rather than importing
private development history. Existing v0.6.0 projects remain compatible, but
users should review the structured output of an edit before rendering because
MovieStar is still pre-1.0.

## Install

After v0.7.0 is published to PyPI:

```bash
pip install --upgrade "moviestar==0.7.0"
moviestar doctor
```

Until then, follow the repository's
[getting-started guide](../getting-started.md) to install the current public
source.
